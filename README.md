# Kid

A small browser-based text-to-video generator.

## What it does

- accepts a text prompt
- turns the prompt into short animated scenes with keyword-based subjects (for example, `horse` or `pig`)
- previews the result on a 1280×720 canvas
- exports the animation as a `.webm` video

## How to use

1. Open `/home/runner/work/Kid/Kid/index.html` in a modern browser.
2. Enter a prompt, choose a style, and pick a duration.
3. Click **Generate Preview**.
4. Click **Download Video** to export the animation.
